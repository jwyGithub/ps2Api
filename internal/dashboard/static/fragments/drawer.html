桌面版获取：打开 Postman 桌面 App → DevTools（F12）→ Application → Local Storage → 找 access_token / multi_login_token；user_id / workspace_id 可在 Network 请求头里找到。

Web 版获取：F12 → Application → Cookies 复制 postman.sid；Console 执行
fetch('https://god.postman.co/api/users/me',{credentials:'include'}).then(r=>r.json()).then(m=>console.log(m.id,(m.user_organizations||{}).organizations))
得到 user_id / workspace_id（orgs[0].id）/ subdomain（m.username 小写）。
