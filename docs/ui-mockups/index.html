如何使用：用浏览器打开本页（docs/ui-mockups/index.html），点击任一卡片进入原型。三套方案的页面结构、内容、交互完全一致，只有视觉风格不同，方便你横向对比。
可以点的交互：左侧 7 个导航实时切换页面；账号页卡片/列表视图切换、搜索/筛选、启停开关；API Key 页「新建 Key」弹窗生成密钥并一次性展示+复制、删除；模型页启停开关 + 单模型「测试」（异步延迟）；代理页测试连通/延迟、启停、删除；统计页今天/24h/7d/30d 区间切换重绘图表；系统设置开关与保存；右上头像可「退出登录」进入登录页。
选定后：告诉我采用哪套（可混搭，例如「A 的配色 + B 的圆角卡片」），我会把它沉淀为 page/ 的设计令牌（Tailwind v4 + shadcn 主题变量），并据此开始搭建正式页面。
